1. Executive Summary: The Market Disruption Strategy

Most B2B lead platforms (Apollo, ZoomInfo, Hunter) ration credits aggressively to force users into costly upgrades. Because ContractorLeads.us operates a zero-cost proprietary scraper and internal database for standard leads, combined with an on-demand external waterfall engine, our baseline cost per lead is only 1.5 to 2.0 cents. This allows us to provide 3x to 4x more leads than competitors while maintaining 60% to 85% gross margins.

Two-Tier Consumption Architecture:

  • Tier 1: Standard Discovery & Search (1 Credit): Company name, address, website, general office phone, Google rating, and review count. Resolved via our proprietary scraper and internal database at $0.00 in external API costs.
  • Tier 2: Optional On-Demand Deep Enrichment (+2 Credits): Verified owner/founder name, job title, 100% SMTP-tested personal & work emails, direct mobile phone, and LinkedIn URL. Triggered strictly on-demand when the user clicks "Deep Enrich". Never run automatically. 0 extra credits charged if unresolvable.

6. Core Operating Rules Configured in Codebase

  • 1. Strict On-Demand Execution: Regular search, map discovery, and viewing contacts run locally and never invoke paid third-party APIs. External APIs are queried only when the user explicitly clicks the "Deep Enrich (+2 cr)" action button.
  • 2. No-Charge-On-Miss Guarantee: If external APIs return no verified contact record, 0 extra credits are deducted from the customer's balance. This eliminates customer support disputes.
  • 3. Dynamic Admin Control: The optional enrichment fee (default: 2 credits) is fully editable at any time from Admin Console -> Plans & Pricing without code changes or server redeployments.
  • 4. Automatic Direct SMTP Relay Failover: Hostinger relay gateway on roofingclients.us is prioritized first, with seamless direct authenticated SMTP fallback ensuring 100% delivery for warmup and campaign verification.
